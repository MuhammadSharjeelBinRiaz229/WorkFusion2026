# WorkFusion: One Platform For Every Skill

WorkFusion is an AI-powered hybrid employment marketplace that unifies online freelancing and physical service hiring into a single intelligent platform.

## Repository Structure

- `client/`: Next.js frontend application.
- `server/`: Node.js Express server.
- `recommendation-service/`: Python FastAPI AI recommendation service.
- `shared/`: Shared TypeScript models, interfaces, and schemas.
- `docs/`: Master architectural and specification documentation.

## Setup Instructions

See configuration instructions in the `docs/` folder for backend, frontend, and AI setup details.
